# 🚕 OLA Ride Insights – Data Analytics Project

An end-to-end data analytics project focused on analyzing OLA ride data to uncover demand patterns, ride trends, peak hours, and business insights using Python, SQL, and an interactive Streamlit dashboard.

---

## 📌 Project Objective

The goal of this project is to:
- Analyze OLA ride data to understand customer demand and ride behavior
- Identify peak hours, ride trends, and key operational insights
- Build an interactive dashboard for easy data exploration
- Showcase practical data analytics skills for real-world business use cases.
